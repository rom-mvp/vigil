Integration Guide

Add Vigil to your application:

curl -X POST https://vigil.your-domain.com/api/check \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "agent_id": "my-agent",
    "request": "user message here"
  }'
